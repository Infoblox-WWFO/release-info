# release-info

Version manifests for WWFO tools. Each tool has its own JSON file. Tools fetch
their file at startup and compare against the locally installed version to surface
update notifications in the UI.

## Structure

Each file is named after the tool it describes:

```
infoblox-estimate.json          # Infoblox Estimate
```

## Infoblox Estimate

Infoblox Estimate is a small toolkit you run on your own machine to count the
DDI and security resources in your environment. It counts only — it reads no
record contents, stores nothing outside the folder you unzip, and sends nothing
anywhere. You choose what to share with your Infoblox representative.

**Current version: 2.0.1**

[Download infoblox-estimate-2.0.1.zip](https://github.com/Infoblox-WWFO/release-info/releases/download/estimate-v2.0.1/infoblox-estimate-2.0.1.zip) (0.8 MB)

### Running it

1. Download the ZIP above and unzip it.
2. Open `infoblox-estimate/index.html` in your browser.
3. Follow the steps on the page.
